1الملخص التنفيذي

ParkShield يستبدل رقم الهاتف المكتوب خلف زجاج السيارة بملصق QR. أي شخص (مشاة أو سائق) يمسح الملصق يرسل تنبيهًا لصاحب السيارة خلال ثوانٍ: السيارة تسد مخرجًا، أو النور مضاء، أو النافذة مفتوحة، أو هناك ضرر. لا يحتاج الماسح لتطبيق أو حساب، ولا يرى أي طرف رقم الآخر.

المشكلة

في ألمانيا يترك كثير من السائقين رقم هاتفهم خلف الزجاج لحالات الركن الخاطئ. هذا يعرّضهم للإزعاج وجمع الأرقام لأغراض تسويقية واحتيالية، ويتعارض مع ثقافة الخصوصية القوية هناك. في المقابل، من تُسدّ سيارته لا يجد طريقة للتواصل غير استدعاء الشرطة أو شركة السحب، وهذا مكلف ومزعج للطرفين.

الحل

ملصق QR شخصي ومشفّر يفتح صفحة ويب سريعة (PWA) بلغة الماسح. يختار الماسح نوع المشكلة بضغطة واحدة، فيصل التنبيه للمالك عبر Push أو WhatsApp أو SMS أو بريد، مع زر „Ich komme“ (أنا قادم). إذا لم يرد المالك خلال مدة محددة، يُصعَّد التنبيه تلقائيًا لجهة اتصال احتياطية وافقت مسبقًا.

  • 10 محارف Crockford Base32، أي 50 بت. مع حد 20 تنبيهًا يوميًا لكل رمز، يستحيل عمليًا تخمين رمز صالح.
  • لا يُخزَّن إلا SHA-256 في qr_tokens.code_hash، وآخر 4 محارف للدعم الفني.
  • الرابط ثابت والملصق لا يتغير. "التدوير" يعني إلغاء الرمز وطباعة ملصق جديد.

التشفير على مستوى الحقل

  • صيغة الحقل: [إصدار المفتاح 1B][IV 12B][Tag 16B][النص المشفر] بخوارزمية AES-256-GCM.
  • للبحث يُستخدم Blind Index: HMAC-SHA256(key, normalize(value)).
  • تدوير المفاتيح: يُضاف DATA_KEY_V2، والكتابات الجديدة تستخدمه، ومهمة خلفية تعيد تشفير البيانات القديمة.

رموز التأكيد والحالة

  • 256 بت عشوائية، ولا يُخزَّن إلا الـ hash.
  • رمز التأكيد يُستخدم مرة واحدة، ويُمحى من الصف عند الاستخدام.
  • رمز الحالة يبقى في ذاكرة متصفح الماسح فقط (sessionStorage).

تحديد المعدل

  • rl:st:{token}:{ref}: تنبيه واحد كل 15 دقيقة.
  • rl:sg:{ref}: ستة تنبيهات في الساعة.
  • rl:tg:{token}: عشرون تنبيهًا في 24 ساعة.
  • يُقرأ العداد أولًا ثم يُزاد، فلا يُستهلك الرصيد عند الرفض.

13.4 معايير الهندسة وتعريف الإنجاز (Definition of Done)

  • الكود في Pull Request صغير، راجعه شخص آخر، وCI أخضر (Lint وTypecheck وUnit وE2E للمسارات المتأثرة).
  • تغطية اختبارات 80% أو أكثر لوحدات المنطق الأساسي (scan، alerts، escalation، billing، gdpr).
  • اختبارات E2E للمسارات الحرجة: الشراء، والتفعيل، والمسح، والتأكيد، والتصعيد، والإلغاء، وحذف الحساب.
  • النصوص بالألمانية والإنجليزية، وتدقيق axe دون أخطاء، ودعم الوضع الداكن.
  • ترحيلات قاعدة البيانات متوافقة مع الإصدار السابق: إضافة أولًا ثم حذف في إصدار لاحق.
  • لا بيانات شخصية في السجلات (Logs). مراقبة جديدة إن احتاجت الميزة.
  • منشورة على Staging، ويقبلها الـ PO.

-- ---------------------------------------------------------------------------
-- Retention job (run hourly by the worker; idempotent)
-- ---------------------------------------------------------------------------
CREATE FUNCTION run_retention() RETURNS void LANGUAGE plpgsql AS $$
BEGIN
    -- pseudonymous scanner reference: 24 h
    UPDATE alerts SET scanner_ref = NULL
     WHERE scanner_ref IS NOT NULL AND created_at < now() - interval '24 hours';
    -- free-text content: 7 days
    UPDATE alerts SET custom_message_enc = NULL
     WHERE custom_message_enc IS NOT NULL AND created_at < now() - interval '7 days';
    DELETE FROM alert_messages WHERE created_at < now() - interval '7 days';
    -- expire open alerts
    UPDATE alerts SET status = 'expired'
     WHERE status IN ('created','dispatched','delivered') AND expires_at < now();
    -- alert history visible to owner: 90 days
    DELETE FROM alerts WHERE created_at < now() - interval '90 days';
    -- parking location: 24 h after session end
    UPDATE parking_sessions SET location_enc = NULL
     WHERE location_enc IS NOT NULL AND ended_at < now() - interval '24 hours';
    -- shipping addresses: 90 days after delivery (HGB/AO invoice copies live in accounting, not here)
    UPDATE decal_orders SET shipping_address_enc = '\x'::bytea
     WHERE delivered_at < now() - interval '90 days' AND octet_length(shipping_address_enc) > 0;
    -- expired auth artefacts
    DELETE FROM magic_link_tokens WHERE expires_at < now() - interval '1 day';
    DELETE FROM sessions WHERE expires_at < now() - interval '7 days';
    DELETE FROM scanner_blocks WHERE expires_at < now();
    -- declined / unanswered emergency-contact invitations: 14 days
    DELETE FROM emergency_contacts
     WHERE consent IN ('pending','declined') AND consent_requested_at < now() - interval '14 days';
    -- audit trail: 12 months
    DELETE FROM audit_logs WHERE created_at < now() - interval '12 months';
    DELETE FROM outbox_events WHERE processed_at < now() - interval '7 days';
    -- execute due erasures
    DELETE FROM users WHERE status = 'pending_deletion' AND deletion_due_at < now();
END $$;
